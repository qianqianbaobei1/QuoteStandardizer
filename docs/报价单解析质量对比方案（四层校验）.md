3. 判定口径。 每条报价行在 L1–L4 各得一个状态：PASS / FAIL / PENDING。四层全 PASS 才算通过；任一 FAIL 即不通过；无 FAIL 但有 PENDING 记“待确认”，不计入通过率分子。格式差异不导致 FAIL，但要单独统计。
4. 问题只算一次根因。 同一页脚条款漏提会让该页所有行 FAIL，统计时既要按行计（23 行受影响），也要按根因计（1 个问题），避免一个全局缺陷把统计冲淡。

2.2 步骤
1. 统一结构：把两份结果都转成“一行一条报价 + 字段字典”的长表。标准合并所有 sheet，补一列类别编码；线上把「规格参数」按换行拆成「属性名:值」对（跳过首行「规格（属性值）:…」）。
2. 建立原图真值表：逐页读原始报价单，写出每页的材料行（品牌、名称、规格原文、单位、单价）与页级信息（抬头、报价单位、联系人、报价日期、备注条款）。先数行数并记录。只在线上与标准有分歧时才需要精读对应行，但行数和页级信息每页都要读。
3. 行对齐（见 2.3）：得到三类行：已配对、仅线上（多提/重复）、仅标准（线上漏提）。
4. 字段归一化（见 2.4）后逐字段比对，生成字段级差异。
5. 差异裁决：对每个差异按字段来源类别去查原图/规则/配置/接口，给出裁决结果和证据（原图位置或接口返回）。
6. 四层判定（见第三节）：每行得出 L1–L4 状态和总状态。
7. 统计与归因（见第四节），输出报告 Excel。
8. 自检：抽 10% 差异行（至少 5 条）重新对照原图复核；核对行数守恒（已配对 + 仅线上 = 线上总行数；已配对 + 仅标准 = 标准总行数）。
2.3 行对齐规则
不能用报价 ID（标准为空），也不能用顺序号（标准 1,2,3…，线上 10,20,30…）。按以下顺序配对：
1. 精确键：报价文件名 + 页码 + 归一化名称 + 归一化原始规格参数 + 市场价。
2. 放宽键：去掉市场价再配；配上的行在 L1 记“单价差异”。
3. 模糊键：同页内按规格文本相似度 ≥ 0.9 + 行序接近配对；记“规格文本差异”。
4. 重复键按多重集合配对：同一键标准有 n 条、线上有 m 条，只配 min(n,m) 条，多出的进入“仅线上/仅标准”，再拿原图行数判定到底是谁多了。样例里线上 GBU00140/GBU00150 就是这种情况。

L4 图片链接与报价页图
4a 产品图片（末尾「图片文件夹」「图片」列）
1. 按类别编码 + 名称 + 关键属性（如排气扇的类型）调图片库接口，得到应挂的图片文件夹和文件。
2. 检查线上图片文件夹是否等于接口结果（不等 → L4-FOLDER）。
3. 对每个图片 URL 发 HEAD/GET：状态码 200、Content-Type 为 image/*、大小 > 1 KB；否则 L4-DEAD。
4. 检查 URL 路径里的文件夹与「图片文件夹」列一致（不一致 → L4-PATH）。
5. 接口有图而线上为空 → L4-EMPTY；接口无图且线上为空 → PASS。
6. 可选：用视觉模型看一眼图片内容是否是该品种（壁挂式排气扇不应配管道式图）→ L4-WRONGPIC。
样例里标准写的是文件名（消声静压箱01.jpg），线上写的是 OSS 完整 URL，两者不能直接字符串比，一律以接口结果为准。
4b 厂家报价页图（前部「厂家报价图片文件名」「页码」列）
1. 文件名必须是本批原始文件之一（不存在 → L4-SRC-FILE）。
2. 页码必须是该材料真实所在页：在该页原文里能找到这一行的规格和单价（找不到 → L4-SRC-PAGE）。多份、多页报价单时这是重点。
3. 嵌入的页图必须是整页、不裁切：与原页渲染图比对宽高比和感知哈希（pHash 距离 ≤ 10），否则 L4-SRC-IMG。同一页的所有行应嵌入同一张图。

统计口径
• 整体通过率 = 四层全 PASS 的行 ÷ 原图真实行数。分母用原图行数，而不是线上行数，这样漏行会拉低通过率，多出的重复行另计。
• 各层通过率 = 该层 PASS 行 ÷ 该层有判定的行（不含 PENDING）。
• 首要失败层：只给每个失败行记一个“最上游”的失败层（L1 > L2 > L3 > L4），用来回答“问题主要集中在哪里”；同时保留各层独立失败数。
• 根因去重：页级问题（L1-TERMS、L1-DATE、L1-SUPPLIER、L4-SRC-*）按“文件+页”算 1 个根因；图片问题按“类别+文件夹”算 1 个根因。
• 维度交叉：问题编码 × 类别编码、问题编码 × 原始文件类型（扫描图/PDF/Excel）、问题编码 × 页内位置（页尾、切图边界）。
• 格式差异单独列一个计数，提示统一输出规范，不进失败率。
多批次汇总时，按问题编码做帕累托排序，前几项就是“问题主要集中在哪里”的答案。
