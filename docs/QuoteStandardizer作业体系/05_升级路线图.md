# 05 · 升级路线图

每个阶段都有**准入条件**（前一阶段必须达到的状态）和**完成标准**。阶段内的具体任务由大脑拆成工单下达，执行者不得跳阶段实施。

## 阶段总览

| 阶段 | 主题 | 状态 |
|---|---|---|
| P0 | 地基：版本、标准答案、回归、第 1 批缺陷 | **进行中**（`02_缺陷修复工单_第1批.md`） |
| P1 | 自检与效率 | 待 P0 完成 |
| P2 | 表格结构覆盖 | 待 P1 完成 |
| P3 | 判定引擎升级（Jev）与分类编码 | 待 P2 完成，并需用户决策 |
| P4 | 规模化运行 | 待 P3 完成 |

---

## P0 地基
- **内容**：F0、G1、R1、F1–F7。
- **完成标准**：S1–S5 全部通过绝对门禁；`指标趋势.csv` 有第一条已接受基线。

## P1 自检与效率
**准入**：P0 完成。

| 任务 | 说明 | 完成标准 |
|---|---|---|
| 运行时自检 | 实现 `04` 第 5 节 | 人为注入每类违反都能被拦下 |
| 商务条款双读 | 商务单识别两遍（增强图 + 原图），逐字段比对，不一致的字段标待复核 | S1–S5 商务条款准确率不下降，误判字段都被标记 |
| 表头推导提示词修正 | 示例 JSON 去掉 `//` 注释；样本行数由 8 行增至 15 行；解析失败要在日志中显式提示 | 回归不退步 |
| 视觉识别并发 | 同一页两遍识别并发；多页之间并发（并发数可配置） | 结果不变，耗时下降（回报中给出前后对比） |
| 清洗并发 | 清洗批次并发执行 | 结果不变，耗时下降 |
| 规范参数不调模型 | 整行参数已是“键:值;”且名称列明确时，名称与参数直接由程序生成 | 结果不变，调用次数下降 |
| 推理模式开关 | 增加关闭 DeepSeek 推理模式的配置项，先在标准答案集上对比准确率和耗时 | 仅当准确率不下降时才允许设为默认 |

**完成标准**：全部样例通过门禁；单样例总耗时较 P0 基线下降至少 30%。

## P2 表格结构覆盖
**准入**：P1 完成。

| 任务 | 说明 |
|---|---|
| 跨页续表 | 后续页没有表头时，沿用上一页同结构表格的表头；判定依据（列数一致等）写入对账 |
| 一页多表（上下叠放） | 一页/一 Sheet 内多张表分别识别与解析 |
| 扫描件左右并排子表 | 视觉转录结果中的并排子表拆分 |
| 旧版 `.xls` | 转换后走 Excel 流程（转换方式需大脑批准） |

**完成标准**：每类结构至少有 1 份真实样例进入标准答案集并通过门禁（样例由用户提供）。

## P3 判定引擎升级与分类编码
**准入**：P2 完成；用户已决定是否允许把报价单内容发送给 TypeSafe；用户已提供标准分类编码库（如需做编码）。

| 任务 | 说明 | 决策依据 |
|---|---|---|
| Jev 结构/行类型 | 按 `03` 第 3.1 节在全部标准答案样例上做对比 | Jev 在分歧项上判对更多，且漏报不增加，才允许设为默认 |
| 分类编码 | 编码库按层级做 Jev 选择题（先大类后小类，保留前几个候选），低置信度标待复核 | 在标注了正确编码的样例上，准确率与低置信度拦截率达到大脑设定的阈值 |
| 公章互证 | 用 Jev 判断“公章识别的公司名与文件名/表格中的名称是否为同一公司”，替代字符规则 | 误拒和误收都不增加 |
| Jev 置信度阈值校准 | 用积累的对比数据确定 `JEV_MIN_CONFIDENCE` | 低于阈值的项中错误占比显著高于阈值以上 |

## P4 规模化运行
**准入**：P3 完成，或用户决定跳过 P3。

| 任务 | 说明 |
|---|---|
| 批量入口 | 一次处理一个目录下的全部报价单，生成汇总报告 |
| 转录缓存 | 按原件 sha256 缓存视觉转录结果，重复运行不重复调用（稳定性测试时可关闭） |
| 成本与质量看板 | 汇总每批的调用次数、token、耗时，以及各项门禁指标 |
| 上线标准 | 由用户确定（例如：连续 N 批正式材料“可直接使用”比例达到某值） |
