## 一、审查核心三大公理（Core Axioms）

### 公理 1：三方裁决，原图是唯一终审裁判（打破“标准即绝对真值”的盲信）
在比对测试中，本地模型生成的“标准答案”或历史标注结果**本身并非绝对完美**（可能存在 OCR 偶发性错字、漏提全局备注条款、或无依据填充外部字段）。
- 比对流程必须先将「线上解析」与「标准答案」进行对账。
- **一致项**：直接通过。
- **分歧项**：**严禁用“标准”直接否定“线上”**，必须回溯原始报价单原图进行像素级精读。
  - 原图支持线上：判定线上正确，并将分歧记入**「标准待修正清单」**，反哺基准库。
  - 原图支持标准：判定线上错误，记入线上缺陷。
  - 双方均与原图不符：判定双方都错，记入线上缺陷并同时反哺修正标准。

### 公理 2：字段按源施策（Source-Driven Verification）
字段属性必须先分清其生产来源，才能决定审查方法。严禁拿原图去判外部配置字段，严禁拿规则字段当作版面直见字段。

### 公理 3：绝对一票否决与根因去重并存（Strict Pass & Root-Cause Deduplication）
- **行级/文件级通过性**：执行**绝对一票否决制**。单行在 L1~L4 中只要有 1 项未达成，该行即 FAIL；整份文件中只要有 1 行 FAIL，整份文件综合判定即判为 FAIL。
- **统计分析归因**：同一页脚备注漏提（如“报价含税，不含运费”）会级联影响该页所有材料行，统计时记录“受影响行数（如 23 行）”，同时归并为“**1 个根因问题（L1-TERMS）**”，避免全局缺陷稀释其他独立缺陷。

## 二、字段来源分类与比对基准（A/B/C/D 分类法）

| 来源分类 | 包含字段清单 | 校验与比对基准 | 异常裁决规则 |
| :--- | :--- | :--- | :--- |
| **A 类：原图直见** | 名称规格、品牌、厂家原始规格参数、单位、市场价、供应商名称、报价时间、是否含增值税、是否含运费、运费说明、页脚不含项备注 | **原始报价单原图**（逐行版面/文字/图表切片） | 原图无此信息或与原图不符即判错；原图清晰可见而字段未提取判漏提。 |
| **B 类：规则派生** | 类别编码（三级工料机）、规格参数动态物理属性键值对、工程价（=市场价×折扣）、报价ID、顺序号、页码 | **工料机类别词典**、**品类属性模板**、计算规则 | 类别编码必须符合国标三级体系；属性拆解必须符合该类目必填参数模板；工程价必须与公式计算一致。 |
| **C 类：外部配置** | 增值税率（如13%）、两票制、现款现结、折扣比例/上下限/系列、价格填报类型、报价地区 | **业务任务商务配置表** | 若原图无体现且业务未下发该批次配置，**一律标记为 `PENDING`（待人工确认）**，严禁模型胡乱编造。 |
| **D 类：图片资源** | 产品图片文件夹、产品图 OSS URL、厂家报价原切片文件名、内嵌整页缩略图 | **广材图片库接口**、HTTP 可访问性、原图文件系统 | 产品图检查接口文件夹与 HTTP 200 解码；厂家报价页图检查物理文件存在且为无裁切整页。 |

## 三、四层质量校验指标与判定标准（L1–L4 检验图谱）

```
┌────────────────────────────────────────────────────────────────────────┐
│                        四层校验质量关卡架构                             │
├───────────────────┬────────────────────────────────────────────────────┤
│ L1 图片解析       │ 内容提全、维度提出（行数守恒、单价、单位、页级商务条款）   │
├───────────────────┼────────────────────────────────────────────────────┤
│ L2 材料分类       │ 三级工料机类别编码 100% 命中、名称↔编码强一致           │
├───────────────────┼────────────────────────────────────────────────────┤
│ L3 规格型号       │ 动态物理参数按模板全拆解，严禁凭空编造（防幻觉）          │
├───────────────────┼────────────────────────────────────────────────────┤
│ L4 图片凭证       │ 产品图库接口有效挂接、原件整页切片凭证及页码索引 100% 覆盖 │
└───────────────────┴────────────────────────────────────────────────────┘
```

### L1：图片解析（内容提全、维度提出）
目标：确保原图上每一行材料数据、每一个页级商务条款均被无遗漏、无冗余地提取。

| 检查项 | 粒度 | 判定不通过（FAIL）条件 | 标准问题编码 | 审查重点与避坑指南 |
| :--- | :---: | :--- | :--- | :--- |
| **行数守恒** | 单页/文件 | 线上行数 ≠ 原图物理材料行数 | `L1-ROW-MISS` (漏行)<br>`L1-ROW-DUP` (重复行)<br>`L1-ROW-EXTRA` (多提非材料行) | 常见于切图接缝重叠导致的重复识别（如 GBU00140 与 GBU00150），或表尾合计行误提为物料。 |
| **厂家原始规格** | 行 | 归一化后与原图原文不符 | `L1-SPEC-TEXT` | 原文标点、连接符（`x` vs `×`）走归一化容错，字符 OCR 错字判否。 |
| **基础三要素** | 行 | 名称、品牌、单位与原图不符或为空 | `L1-NAME`<br>`L1-BRAND`<br>`L1-UNIT` | 单位换算（如米折吨）需记录为口径差，原件有单位而解析漏填判否。 |
| **市场价** | 行 | 数值不一致（含小数点错位、串列） | `L1-PRICE` | 允许 0.01 误差。线上私自计算折后价而未填票面价视为错值。 |
| **供应商抬头** | 页/文件 | 与抬头章印、报价单位不一致或为空 | `L1-SUPPLIER` | 报价单抬头公司全称必须精准提取。 |
| **报价时间** | 页/文件 | 原图有明确日期但未提或提取错误 | `L1-DATE` | 原图右上角或落款日期必须提取，格式归一为 `YYYY-MM-DD`。 |
| **页脚商务条款** | 页/文件 | 原图备注写明而字段为空、取反或残缺 | `L1-TERMS` | **极高发漏洞**：“报价含税”、“不含运费”、“运费180元/m³”、“不含安装费/软接/减震器”必须完整提取并结构化入库。 |
| **工程价一致性** | 行 | 工程价 ≠ 市场价 × 折扣比例 | `L1-ENGPRICE` | 无折扣依据填工程价，或批注写留空而单元格有值，判自相矛盾。 |

### L2：材料分类（三级工料机精准映射）
目标：建立物料名称到工料机标准类目的精准映射，杜绝泛化粗放归类。

| 检查项 | 判定不通过（FAIL）条件 | 标准问题编码 | 审查重点与避坑指南 |
| :--- | :--- | :--- | :--- |
| **类别编码** | 线上编码与标准三级编码不符且裁决为错 | `L2-CODE` | 必须精确到三级类目（如 `19-59-01` 消声静压箱、`50-35-01` 排气扇）。 |
| **编码合法性** | 编码不在最新工料机分类库，或层级不足三级 | `L2-INVALID` | 禁止随意生成虚构编码；必须在工料机大字典中真实存在。 |
| **类目名称匹配**| 类别标准名与编码对应标准名不符 | `L2-NAME` | 防止编码与名称张冠李戴。 |
| **同名同码一致性**| 同一份单据中完全相同的材料名称被分到不同类目 | `L2-INCONSIST` | 同名同规格物料分类必须具备确定性闭环。 |

### L3：规格型号（属性结构化拆分）
目标：将半结构化的规格字符串，按照类目属性模板拆解为物理参数（长/宽/高/厚度/材质/风量/功率等）。

| 检查项 | 判定不通过（FAIL）条件 | 标准问题编码 | 审查重点与避坑指南 |
| :--- | :--- | :--- | :--- |
| **必填属性缺失** | 缺少该三级类目模板定义的必填属性 | `L3-ATTR-MISS` | 如消声静压箱必须包含“品种、材质、规格”；排气扇必须包含“风量、功率、类型”。 |
| **模板外多余属性**| 拆出了模板之外且不可识别的冗余字段 | `L3-ATTR-EXTRA` | 若属于行业通用物理维度则允许，非物理垃圾词判否。 |
| **属性值放错** | 属性值正确但键名颠倒 | `L3-ATTR-SWAP` | 如将风量数值填入功率，或长宽颠倒。 |
| **数值与单位准确**| 属性数值拆错，或单位与模板不一致且未换算 | `L3-VALUE`<br>`L3-UNIT` | 截取字符截断、复合尺寸拆错均属于此类。 |
| **幻觉编造** | 拆出的属性值在厂家原始规格中完全无依据 | `L3-HALLU` | **红线严惩**：模型凭空脑补参数（如原件未写材质却填“不锈钢”）。 |

### L4：图片凭证（产品图挂接与整页单据证据）
目标：实现每行物料兼具“标准产品示意图”与“原始报价凭证定位切片”。

| 维度 | 检查项 | 判定不通过（FAIL）条件 | 标准问题编码 | 审查标准 |
| :---: | :--- | :--- | :--- | :--- |
| **4a 产品图片** | 图库接口对齐 | 线上图片文件夹与图库接口标准推荐不一致 | `L4-FOLDER` | 如消声静压箱应挂 `m0000871` 还是 `m0000498`，需调接口确定。 |
|  | 图片链接有效性 | 图片 URL 状态码非 200，无法解码或大小 < 1KB | `L4-DEAD` | HTTP 请求探测连通性。 |
|  | 应有图而缺失 | 接口该类目有图，但线上该字段全空 | `L4-EMPTY` | 典型如排气扇接口有图，但线上物料未挂接任何图片。 |
| **4b 报价原件图** | 凭证切片文件名 | 文件名不在本批次原始接收的图集列表中 | `L4-SRC-FILE` | 必须能准确回溯物理图片文件。 |
|  | 原件页码真实性 | 标注的页码在原图中找不到该行物料与单价 | `L4-SRC-PAGE` | 多页报价单重点：严防把第 3 页物料标注在第 1 页。 |
|  | 整页图完整性 | 嵌入的页面图被残缺裁剪、非整页 | `L4-SRC-IMG` | 嵌入图必须为整页原图，宽高比与感知哈希（pHash 距离 ≤ 10）必须吻合。 |

## 四、数据归一化与行对齐算法标准

在进行比对前，必须先将两端数据执行**无损归一化（Normalization）**，消除字符格式层面的伪分歧：

```
原始字符串 ➔ [NFKC 全角转半角] ➔ [去除空格与不可见字符] ➔ [统一乘号为 '×'] ➔ [单位映射表收敛] ➔ 归一化比对键
```

### 1. 归一化对照表

| 对象 | 转换规则 | 示例输入 | 归一化结果 |
| :--- | :--- | :--- | :--- |
| **标点符号** | 全角转半角，中英文冒号/分号/括号统一，去除无意义空格 | `规格（mm）： 1200` | `规格(mm):1200` |
| **乘号连接符** | `*`、`x`、`X`、`✖` 统一替换为标准乘号 `×` | `1300x900X850` | `1300×900×850` |
| **货币数值** | 剔除货币符号（¥/$）、千分位逗号，解析为浮点数保留 2 位小数 | `¥ 1,254.00` | `1254.0` |
| **工程单位** | 面积/体积符号标准化 | `m2`、`平方米` ➔ `m²`；`m3`、`立方` ➔ `m³` | `m²` / `m³` |
| **属性顺序** | 字典化键值对（Key-Value Map），比对时按属性名匹配，忽略列排列次序 | `功率:150;风量:800` vs `风量:800;功率:150` | 判定完全等价 |
| **顺序号/行号** | 不比对绝对值，仅检查是否保持原图单调递增 | 线上 `10, 20, 30` vs 标准 `1, 2, 3` | 判定一致通过 |

### 2. 多级级联行对齐机制（Cascaded Row Matching）
严禁依赖无意义的自增 ID 匹配，必须采用四级级联匹配漏斗：
1. **精确级联键**：`厂家报价图片文件名 + 页码 + 归一化名称 + 归一化原始规格 + 市场价`。
2. **放宽级联键**：去除市场价，按 `文件名 + 页码 + 归一化名称 + 归一化原始规格` 配对（配对成功的行单价不同，在 L1 记 `L1-PRICE` 差异）。
3. **模糊级联键**：同页内按 `规格文本相似度 ≥ 0.9 + 行序绝对差最小` 配对（记 `规格文本差异`）。
4. **多重集合对齐（Multiset Matching）**：同页出现完全相同键时，标准有 $n$ 条、线上有 $m$ 条，只能配对 $\min(n, m)$ 条；多出的行直接判定为 `L1-ROW-DUP`（重复切片）或 `L1-ROW-MISS`（遗漏行）。

## 五、综合判定口径与一票否决核算模型

### 1. 行级判定逻辑
对每行计算：
$$\text{RowStatus} = \begin{cases} 
\text{PASS}, & \text{if } L_1 = \text{PASS} \land L_2 = \text{PASS} \land L_3 = \text{PASS} \land L_4 = \text{PASS} \\ 
\text{PENDING}, & \text{if any } L_i = \text{PENDING} \text{ and others } = \text{PASS} \\ 
\text{FAIL}, & \text{if any } L_i = \text{FAIL} 
\end{cases}$$

### 2. 文件级与批次级通过率（严禁以线上行为分母）

- **全网物理真实行通过率（行级）**：
  $$\text{行级综合通过率} = \frac{\sum \text{四层全 PASS 的真实材料行数}}{\text{原图真实物理行数（绝对真值分母）}}$$
  > **核心考量**：分母绝不可用“线上解析行数”。如果原图有 100 行，线上漏掉 50 行，只解出 50 行全对；若以线上为分母会虚高成 100%，以原图为分母则真实反映为 50%。

- **文件级通过率（绝对一票否决制）**：
  $$\text{文件通过条件} = \left(\text{该文件内真实材料行数} = \text{原图行数}\right) \land \left(\forall \text{行} \in \text{文件}, \text{RowStatus} = \text{PASS}\right)$$
  $$\text{文件级综合通过率} = \frac{\text{四项全能零瑕疵通过的文件数}}{\text{总送评文件数（50 份）}}$$

## 六、标准待修正集（反哺机制）与双重归因模型

### 1. 标准待修正清单（反哺闭环）
任何经原图复核确认为“标准错”或“双方都错”的条目，必须结构化提取至 `标准待修正` 清单中：
- 记录原标准值、正确原图值、以及建议修复原因（如 OCR 错字、无来源字段清理、属性模板缺漏）。
- 定期反向同步至工料机标准库与模型训练集，避免评估标准自身退化。

### 2. 双重归因模型（Dual-Dimensional Attribution）
报告必须同时输出两种维度的归因统计：
- **行级影响面（Impact Scope）**：该缺陷导致多少条物料行判定不通过（用于评估对数据总量的污染面）。
- **根因去重数（Root-Cause Count）**：将同文件、同页面的系统性缺陷归为 1 个根因（用于研发算法帕累托排序定位技术缺陷优先级）。

## 七、交付物与工业级报告标准（5 个 Sheet 结构）

每次评测必须输出且仅输出一个结构完备、格式专业的高内聚 Excel 成果文件，工作表结构严格规定如下：

```
┌────────────────────────────────────────────────────────────────────────┐
│               标准评测报告 Excel 结构 (5 大专用 Sheet)                  │
├───────┬───────────┬────────────────────────────────────────────────────┤
│ 序号  │ Sheet 名称 │ 承载核心内容                                       │
├───────┼───────────┼────────────────────────────────────────────────────┤
│ 1     │ 汇总      │ 整体指标、原图物理总行数、L1~L4达成率、核心结论       │
│ 2     │ 逐行判定   │ 全量物料每行的 L1/L2/L3/L4 判定状态、问题编码列表    │
│ 3     │ 差异明细   │ 字段级三方比对值（标准/线上/原图）、裁决证据出处    │
│ 4     │ 问题归因   │ 根因数、受影响行数、帕累托排序、建议责任系统        │
│ 5     │ 标准待修正 │ 原图裁定为标准错误的条目集，用于反哺基准库          │
└───────┴───────────┴────────────────────────────────────────────────────┘
```

同时，必须同步将数据注入交互式大盘：
- **大盘交付件**：`deliveries/batch_50_eval/报价单解析质量看板.html`
- **视觉硬性规范**：
  - 最顶端必须保持 **4.2rem 巨幅衬线大字醒目展示全要素文件通过率（如 6.0%）**。
  - 必须提供“新旧口径对比图”，且左侧留白必须保持 125px 以上，严格消除文字与坐标轴、数据点的重叠遮挡。
